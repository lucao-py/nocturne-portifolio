# NOCTURNE

Portfólio pessoal de Dados, Engenharia de Dados, Machine Learning e Inteligência Artificial. A Fase 1 contém apenas a fundação técnica e uma página provisória.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse <http://localhost:3000>. Nenhuma variável de ambiente é necessária nesta fase.

## Verificações

```bash
npm run lint
npm run typecheck
npm run build
```

## Estrutura inicial

- `src/app`: layout, estilos globais e rota inicial do App Router.
- `src/components`: espaço para componentes reutilizáveis quando surgirem nas próximas fases.
- `src/styles`: tokens CSS iniciais definidos no Design System.
- `public`: assets próprios ou licenciados, quando necessários.
- `docs`: documentação do produto e da arquitetura.

Consulte `docs/PRD.md`, `docs/ARCHITECTURE.md` e o roadmap antes de avançar de fase.
